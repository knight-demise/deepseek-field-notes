## 运行

```bash
npm install
npm run dev
```

打开：

- #01 中文：`http://localhost:3000/zh/field-notes/01-deepseek-harness`
- #01 English：`http://localhost:3000/en/field-notes/01-deepseek-harness`
- #02 中文：`http://localhost:3000/zh/field-notes/02-v4-pro-research-frontier`
- #02 English：`http://localhost:3000/en/field-notes/02-v4-pro-research-frontier`

- #03 English：`http://localhost:3000/en/field-notes/03-centralized-substrate-decentralized-search`

npm run lint
